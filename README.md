## 📌 Sobre o Projeto

Projeto desenvolvido com foco na criação de uma interface moderna, responsiva e intuitiva, aplicando boas práticas de desenvolvimento front-end.

### 🎯 Objetivo

Praticar a construção de interfaces responsivas utilizando HTML5, CSS3 e JavaScript, além de aplicar conceitos de UX/UI desenvolvidos no Figma.

---

## 🎨 UX/UI

- Interface moderna e intuitiva
- Layout responsivo
- Design desenvolvido no Figma
- Navegação simplificada
- Adaptação para diferentes dispositivos

---

## ✨ Funcionalidades
